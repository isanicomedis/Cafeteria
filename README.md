# Cafeteria ☕

Página web de uma cafeteria, desenvolvida para praticar HTML e CSS.

## Seções

- **Home** — banner principal
- **Sobre** — descrição da cafeteria
- **Menu** — itens disponíveis
- **Avaliações** — depoimentos de clientes
- **Endereço** — localização com mapa integrado

## Tecnologias

- HTML5
- CSS3

## Como visualizar

Basta abrir o arquivo `index.html` no navegador.

Ou acesse pelo GitHub Pages: [isanicomedis.github.io/Cafeteria](https://isanicomedis.github.io/Cafeteria)
